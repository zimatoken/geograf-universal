# 🌍 Я в натуре Географ v2.0

Приложение для изучения географии — 50 стран мира.

## Возможности
- 50 стран мира
- Справочник с деталями
- Открытие стран
- XP, уровни, достижения
- PWA и оффлайн

## Запуск
cd geograf-universal-v2.0
py -m http.server 8000
http://localhost:8000
